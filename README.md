# Serial Number Register Frontend (React + Vite)

Clean, mobile-first responsive React frontend for Name & Serial / Barcode Register with real-time duplicate counting, live scanner support, audio beeps, and CSV export.

## 🚀 Setup & Installation

1. Install dependencies:
```bash
npm install
```

2. Start development server:
```bash
npm run dev
```

3. Build for production:
```bash
npm run build
```
